# ADR-003: MenuPackage contains authoritative published menu commercial configuration

## Status
Accepted

## Context
Pricing and menu configuration should be managed in a central "Menu Catalog" (Cuentame) and published to terminals.

## Decision
The `MenuPackage` is the authoritative source for MenuItem identity, names, categories, selling prices, and discount eligibility. 

## Consequences
- Inconsistent prices across multiple terminals are prevented.
- Cashiers cannot independently change authoritative prices on the terminal.
