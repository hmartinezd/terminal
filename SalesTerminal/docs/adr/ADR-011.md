# ADR-011: Room schema export is enabled for migration tracking

## Status
Accepted

## Context
As the application evolves, the database schema will change. We need a reliable way to track schema history and test migrations.

## Decision
We will enable Room's schema export feature (`exportSchema = true`). Generated schema JSON files will be stored in the `app/schemas` directory and committed to version control.

## Consequences
- Clear history of database schema changes.
- Foundation for automated migration testing.
- Requirement to ensure build environment (KSP) is configured with a consistent schema location.
