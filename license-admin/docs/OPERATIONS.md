# Operational checklist

- Verify the activation request fields and operator authorization.
- Use private and public key paths outside the source tree.
- Confirm binding, plan, sequence, expiration, and grace before typing `YES`.
- Store output and audit securely; back up the production key offline.
- For renewal, verify the current license and preserve all binding fields.
- For device replacement, require a new activation request and explicit issuance.
