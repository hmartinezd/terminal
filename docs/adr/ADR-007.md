# ADR-007: Sale lifecycle ordering uses monotonic revision

## Status
Accepted

## Context
Device clocks can be unreliable or out of sync. We need a reliable way to determine the precedence of sale states.

## Decision
Sale lifecycle states (OPEN -> COMPLETED -> VOIDED) will be tracked using a monotonic logical revision number.

## Consequences
- State precedence is determined by the revision number, not by timestamps.
- Handles out-of-order state deliveries in integration scenarios safely.
