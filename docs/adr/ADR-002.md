# ADR-002: Sales Terminal and Cuentame communicate only through versioned contracts

## Status
Accepted

## Context
Sales Terminal and Cuentame are separate applications with different responsibilities. They must never share a database directly.

## Decision
Integration occurs exclusively through stable, explicitly versioned external contracts (MenuPackage for input, SalesBatch for output). 

## Consequences
- Clear separation of concerns.
- Independent evolution of both systems as long as contracts are respected.
- Explicit schema versioning allows for safe upgrades.
