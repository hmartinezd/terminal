# ADR-001: Local-first Room database is terminal operational source of truth

## Status
Accepted

## Context
Sales Terminal must be offline-first and work without any internet or backend dependency for its core ordering and sales workflow.

## Decision
We will use a local Room/SQLite database as the authoritative source of truth for the terminal's operational data (open orders, completed sales, imported menu). 

## Consequences
- No real-time cloud dependency.
- Operations are fast and reliable even with poor connectivity.
- Data must be exported/synced eventually to other systems (like Cuentame).
