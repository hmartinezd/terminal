# ADR-010: SalesBatch is at-least-once and designed for idempotent consumption

## Status
Accepted

## Context
Network exports can fail and be retried. We need to ensure that duplicate exports do not cause double-counting or data duplication.

## Decision
The `SalesBatch` export and the consumer's (Cuentame) import process will be designed for at-least-once delivery and idempotent processing using `saleId` and `revision`.

## Consequences
- Reliable data delivery.
- Duplicate batch or sale processing is safe.
