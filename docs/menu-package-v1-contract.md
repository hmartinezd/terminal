# MenuPackage V1 consumer guardrails

V1 shape remains restaurant/menu/categories/menuItems. Publication revision is a
positive signed Int32 scoped to `(restaurantId, menuId)`, not to the device or
restaurant alone. Item commercial and consumption revisions are also positive
signed Int32. Category and item identifiers must be unique; item category references
must resolve. Unknown additive metadata is tolerated; an unsupported schema version
is rejected rather than guessed.

Import behavior:
- Different restaurant: reject.
- Same menu: lower revision rejects; equal revision succeeds only for semantically
  identical content; higher revision installs.
- Different menu in the same restaurant: independent revision may be lower, equal,
  or higher. Replacement is blocked while orders are open, inside the Room catalog
  replacement transaction. Finish or discard those orders through normal UI first.
- Replacement does not reset Terminal identity, licensing, or sales history.
- This fixes revision identity, NOT arbitrary conflicting same-menu revision data.
  Never disable the same-revision content check or edit a JSON revision manually.

## Limits

Fixtures must be coordinated with producer changes; a copy alone is not a
cross-repository CI gate. Do not change V1 golden expectations just to silence a
failure. Breaking changes need a new schema and coordinated consumer support.
The consumer stores only the currently installed menu; it cannot enforce a historic
high-water revision when switching away and later returning to a previous menu.
Existing same-menu updates while orders are open are unchanged by this patch.
Order creation reads the current menu and inserts its snapshot in the same Room
transaction, serialized against menu replacement. The concurrent regression passed on the phone emulator (10 racing iterations);
this is empirical coverage, not proof of every possible scheduling interleaving.
Neither this patch nor fixture tests establish which data differed in the reported
customer revision-2 conflict without the failed and previously imported packages.
